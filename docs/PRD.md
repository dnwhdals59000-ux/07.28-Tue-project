# Global FX Daily PRD

## 1. 제품 개요

Global FX Daily는 전 세계 환율을 매일 정해진 시각에 저장하고, 한국 원화 기준으로 비교·검색·다운로드할 수 있는 환율 데이터 대시보드다.

## 2. 해결하려는 문제

- 여러 통화의 환율을 한 화면에서 비교하기 어렵다.
- 매일 같은 기준 시각의 환율을 지속적으로 축적하기 어렵다.
- 전일 대비 변화와 과거 추세를 확인하려면 별도 가공이 필요하다.
- 실무용 데이터 다운로드 과정이 번거롭다.

## 3. 목표 사용자

- 수출입 기업의 영업·재무·물류 담당자
- 해외 구매 및 정산 담당자
- 글로벌 시장 데이터를 분석하는 실무자
- 일별 환율 이력이 필요한 개인 사용자

## 4. 핵심 기능

| 기능 | 설명 |
|---|---|
| 일별 자동 적재 | 매일 오전 9시 5분 한국시간에 최신 환율 저장 |
| 당일 수동 보완 | 자동 적재가 누락된 경우에만 당일 최신값 저장 |
| 통화 조회 | 전 세계 지원 통화 검색 및 목록 확인 |
| 기준통화 전환 | USD 또는 KRW 관점으로 환율 표시 |
| 전일 비교 | 전일 대비 등락률 표시 |
| 추세 분석 | 7·30·90·365일 기간별 환율 변화 |
| 환율 계산기 | 선택한 두 통화 간 금액 환산 |
| 데이터 다운로드 | 선택 날짜의 전체 통화를 Excel 호환 CSV로 제공 |

## 5. 데이터 정책

- 원천 데이터: Open Exchange Rates
- 원천 기준통화: USD
- 저장 단위: 통화코드 × 한국 날짜
- 중복 방지키: 기준일 + 통화코드
- 저장 데이터: 환율, 원천 시각, 수집 시각, 기준통화
- 수동 동기화는 이미 저장된 당일 데이터를 덮어쓰지 않는다.

## 6. 성공 지표

- 일별 자동 적재 성공률 99% 이상
- 지원 통화 170개 이상 유지
- 다운로드 요청 성공률 99% 이상
- 페이지 첫 조회 후 데이터 표시 3초 이내
- 모바일·데스크톱 주요 해상도에서 기능 사용 가능

## 7. 제약사항

- 현재 무료 API 요금제는 약 1시간 단위로 환율이 갱신된다.
- 과거 특정 분 단위 환율 복원은 현재 요금제에서 지원되지 않는다.
- 환율은 금융기관의 실제 고객 적용환율과 다를 수 있다.

## 8. 향후 개선

- 전일 환율 숫자와 변동액 직접 표시
- 기간 전체 데이터 일괄 다운로드
- 즐겨찾기 통화
- 급등락 알림
- 무역통계 및 수출실적 환율 환산
- 유료 OHLC API 연동 시 분 단위 과거 환율 지원
