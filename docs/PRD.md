# Global FX Daily 최종 PRD

> 문서 버전: 1.1 · 작성일: 2026-08-03 · 상태: 운영 배포

## 1. 제품 개요

Global FX Daily는 Open Exchange Rates API의 환율을 매일 수집해 Cloudflare D1에 누적하고, 전 세계 통화를 비교·검색·계산·다운로드할 수 있게 하는 로그인 없는 공개 웹 대시보드다.

기본 적재는 한국시간 매일 오전 9시 5분에 실행한다. 최신 환율은 API의 USD 기준 응답을 저장하고, 전체 통화 표는 `1 USD 환율`로 표시한다.

## 2. 문제 정의

- 여러 통화의 환율과 전일 대비 변화를 한 화면에서 확인하기 어렵다.
- 동일한 기준 시각의 일별 환율을 누적하고 과거 데이터와 비교하기 어렵다.
- API 자동 실행이 누락될 때 당일 데이터를 보완할 방법이 필요하다.
- 기간을 지정해 저장된 일별 데이터를 내려받는 과정이 번거롭다.
- API에 존재하는 과거 데이터와 우리 D1에 실제 저장된 데이터의 차이를 구분하기 어렵다.

## 3. 목표와 비목표

### 목표

1. 매일 동일한 시각의 환율을 중복 없이 저장한다.
2. 사용자가 최신 데이터와 저장된 과거 데이터를 로그인 없이 확인하게 한다.
3. 시작일~종료일을 지정해 저장된 일별 환율을 CSV로 다운로드하게 한다.
4. 원천 API, 수집 시각, 저장 기준일을 투명하게 표시한다.

### 비목표

- 금융기관의 실시간 매매기준율 또는 거래 체결 환율 제공
- D1에 저장되지 않은 날짜의 값을 임의로 보간하거나 추정
- Open Exchange Rates의 유료 전용 Time Series 기능을 현재 요금제 확인 없이 자동 사용

## 4. 대상 사용자

- 수출입·구매·영업·재무 담당자
- 해외 결제·견적을 확인하는 실무자
- 글로벌 환율 추세를 분석하는 사용자
- 기간별 환율을 CSV로 내려받아 후속 분석하는 사용자

## 5. 핵심 사용자 흐름

1. 사용자가 로그인 없이 사이트에 접속한다.
2. 최신 기준일과 주요 통화 환율을 확인한다.
3. 전체 통화 목록에서 `1 USD 환율`, 전일 대비, 기준일을 확인한다.
4. 통화명·ISO 코드로 목록을 검색한다.
5. 시작일과 종료일을 선택한다.
6. `조회` 버튼으로 기간을 확정한다.
7. `엑셀 다운로드`를 눌러 해당 기간에 D1에 저장된 일별 환율 CSV를 받는다.
8. 푸터의 Open Exchange Rates 링크에서 원천 데이터 제공처를 확인한다.

## 7. API 및 데이터 정책

### 원천 API

- 최신 데이터: `https://openexchangerates.org/api/latest.json`
- 특정 과거일: `https://openexchangerates.org/api/historical/YYYY-MM-DD.json`
- 기간 조회 가능 API: `https://openexchangerates.org/api/time-series.json`
- 공식 문서: [Historical Rates](https://docs.openexchangerates.org/reference/historical-json), [Time Series](https://docs.openexchangerates.org/reference/time-series-json)
- API 기본 기준 통화: USD
- 날짜·시각 해석: 원천 API는 UTC 기준

### D1 저장

- 저장 단위: `rate_date + currency` 1건
- 저장 값: 기준일, 기준 통화, 통화 코드, 환율, 원천 timestamp, 수집 시각
- 기준일: 수집 시각을 Asia/Seoul로 변환한 날짜
- 동일 기준일: UPSERT로 중복 방지
- 누락 날짜: D1에 저장하지 않은 날짜는 자동 생성·보간하지 않음
- 기간 CSV: 선택 범위 안에 실제 존재하는 저장 행만 반환

### API 요금제 주의

현재 사이트는 `latest.json`을 매일 호출해 자체 D1에 저장한다. Open Exchange Rates의 Historical/Time Series API를 통한 과거 데이터 보충은 계정 요금제와 사용량 제한을 확인한 뒤 별도 기능으로 도입한다. Time Series는 최대 1개월 범위이며 요청 일수만큼 사용량이 차감될 수 있다.

## 8. 제품 API

| 경로 | 설명 |
|---|---|
| `GET /api/rates?days=30&currencies=...` | 최신·이전 저장일, 차트용 이력, 통계 조회 |
| `POST /api/rates/sync?source=scheduled` | 자동 동기화 실행 |
| `POST /api/rates/sync` | 당일 수동 동기화 실행 |
| `GET /api/rates/export?date=YYYY-MM-DD` | 단일 기준일 CSV 다운로드 |
| `GET /api/rates/export?range=custom&from=YYYY-MM-DD&to=YYYY-MM-DD` | 최대 1개월 기간 CSV 다운로드 |

## 10. 비기능 요구사항

- API App ID는 서버 환경변수로만 관리하고 저장소에 커밋하지 않는다.
- 자동 동기화 실패 시 1분 간격 최대 3회 재시도한다.
- configured 상태, 최신 기준일, 저장 통화 수를 자동 검증한다.
- 데이터가 없거나 범위가 잘못된 경우 사용자에게 오류 원인을 표시한다.
- 외부 출처 링크는 새 탭에서 열고 `rel="noreferrer"`를 적용한다.
- 모바일 화면에서 통화 표는 가로 스크롤로 전체 열을 확인할 수 있어야 한다.
- CSV는 UTF-8 BOM과 Excel 호환 형식으로 제공한다.
