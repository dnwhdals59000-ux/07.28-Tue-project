# Global FX Daily 최종 PRD

> 문서 버전: 1.0 · 작성일: 2026-07-28 · 상태: 운영 배포

## 1. 제품 개요

Global FX Daily는 전 세계 통화의 일별 환율을 수집하고, 대한민국 원화(KRW) 기준으로 비교·검색·계산·다운로드할 수 있는 공개 웹 대시보드다. 데이터는 Open Exchange Rates API에서 가져오며, 매일 한국시간 오전 9시 5분에 자동 저장한다.

## 2. 문제 정의

- 여러 통화의 환율과 전일 대비 변화를 한 화면에서 확인하기 어렵다.
- 매일 동일한 기준 시각의 환율을 누적해 추세를 비교하기 어렵다.
- 과거 기준일의 통화별 환율을 재사용하거나 엑셀로 내려받기 번거롭다.
- API 연결이 지연되거나 자동 실행이 누락되었을 때 당일 데이터를 보완할 방법이 필요하다.

## 3. 목표와 성공 지표

### 목표

1. 매일 동일한 기준 시각의 환율 데이터를 안정적으로 누적한다.
2. 사용자가 로그인 없이 최신 환율과 과거 추세를 확인하게 한다.
3. 검색·계산·CSV 다운로드로 실무 활용성을 제공한다.

### 성공 지표

| 지표 | 목표 |
|---|---|
| 자동 동기화 성공률 | 월 99% 이상 |
| 지원 통화 수 | 170개 이상 |
| 첫 화면 데이터 표시 | 3초 이내 |
| CSV 다운로드 성공률 | 99% 이상 |
| 공개 접근성 | 로그인 없이 접근 |

## 4. 대상 사용자

- 수출입·구매·영업·재무 담당자
- 해외 결제와 견적을 확인하는 실무자
- 글로벌 시장 환율 추세를 확인하는 분석 담당자
- 과거 일별 환율 데이터가 필요한 개인 사용자

## 5. 핵심 사용자 흐름

1. 사용자가 사이트에 로그인 없이 접속한다.
2. 최신 기준일, 주요 통화 환율, 전일 대비 변화를 확인한다.
3. KRW 또는 USD 기준을 선택하고 통화별 환산값을 비교한다.
4. 7·30·90·365일 차트에서 선택 통화의 추세를 확인한다.
5. 금액과 통화를 입력해 빠른 환율 계산을 수행한다.
6. 통화명·코드로 검색한 뒤 기준일을 선택해 Excel 호환 CSV를 다운로드한다.
7. 푸터의 공식 출처 링크에서 원천 데이터 제공 사이트를 확인한다.

## 6. 기능 요구사항

| ID | 기능 | 요구사항 | 우선순위 |
|---|---|---|---|
| FR-01 | 최신 환율 조회 | 저장된 최신 기준일의 전 세계 통화와 KRW 환율을 표시한다. | Must |
| FR-02 | 자동 동기화 | 매일 09:05 Asia/Seoul에 `scheduled` 동기화를 실행한다. | Must |
| FR-03 | 당일 환율 동기화 | 자동 동기화가 누락된 경우 사용자가 버튼으로 보완한다. 같은 날짜 데이터가 있으면 중복 저장하지 않는다. | Must |
| FR-04 | 조기 실행 방지 | 09:05 이전에는 당일 환율을 저장하지 않고 안내 메시지를 제공한다. | Must |
| FR-05 | 통화 검색 | 통화명 또는 ISO 코드로 목록을 필터링한다. | Must |
| FR-06 | 기준 통화 전환 | KRW/USD 기준으로 표시 환율을 전환한다. | Must |
| FR-07 | 전일 대비 | 전일 데이터가 있으면 변동률을 표시하고, 없으면 ‘신규’로 표시한다. | Must |
| FR-08 | 추세 차트 | USD, EUR, JPY, CNY, GBP, AUD, CAD의 7·30·90·365일 추세를 제공한다. | Should |
| FR-09 | 환율 계산기 | 금액·출발 통화·도착 통화를 입력해 저장 환율 기준 환산값을 계산한다. | Must |
| FR-10 | Excel 다운로드 | 선택 기준일의 전체 통화, 현재값, 전일값, 변동률을 CSV로 내려받는다. | Must |
| FR-10A | 기간 다운로드 | 시작일~종료일(최대 1개월)을 선택해 저장된 일별 환율을 CSV로 한 번에 내려받는다. | Must |
| FR-11 | 데이터 출처 | 푸터에 Open Exchange Rates 공식 사이트 링크를 제공한다. | Must |
| FR-12 | 반응형 화면 | 데스크톱·태블릿·모바일에서 주요 기능을 사용할 수 있다. | Must |

## 7. 데이터 및 운영 정책

- 원천 데이터: [Open Exchange Rates](https://openexchangerates.org/)
- API 엔드포인트: `https://openexchangerates.org/api/latest.json`
- API 기준 통화: USD
- 주요 카드·계산기 기준 통화: KRW 기본, USD 선택 가능
- 전체 통화 목록: 원천 API 기준인 1 USD 환율로 고정 표시
- 저장 단위: 기준일 + 통화 코드별 1건
- 저장 시각: Asia/Seoul 기준 매일 09:05 이후
- API 무료 요금제의 갱신 주기가 시간 단위일 수 있으므로, 실제 응답 시각과 수집 시각을 함께 기록한다.
- 동일 날짜 데이터는 UPSERT로 중복 저장하지 않는다.
- 자동 동기화 실패 시 최대 3회 재시도하며, 최종 실패는 사용자 알림으로 남긴다.
- 환율은 참고용이며 금융기관의 실제 적용 환율·수수료와 다를 수 있다.

## 8. 기술 구성

- 프런트엔드: React 19, Next.js 호환 vinext, Vite
- 런타임: Cloudflare Workers
- 데이터베이스: Cloudflare D1, Drizzle ORM
- 원천 API: Open Exchange Rates
- 배포: OpenAI Sites
- 저장소: GitHub `dnwhdals59000-ux/07.28-Tue-project`
- 주요 API: `/api/rates`, `/api/rates/sync`, `/api/rates/export`

## 9. 비기능 요구사항

- 인증 없이 공개 접근 가능해야 한다.
- API App ID는 서버 환경변수로만 관리하며 저장소에 커밋하지 않는다.
- 키보드 탐색과 링크의 명확한 접근 이름을 제공한다.
- 외부 링크는 새 탭에서 열고 `rel="noreferrer"`를 적용한다.
- 데이터가 없거나 API 오류가 발생해도 빈 상태·오류 안내를 표시한다.
- 모바일에서 표는 가로 스크롤로 전체 열을 확인할 수 있어야 한다.
